# Repair Onsite Service - โปรแกรมจัดตารางงานซ่อมนอกสถานที่

ระบบบริหารจัดการงานซ่อมนอกสถานที่ (Field Service / Onsite Service Management)

## การติดตั้งและเริ่มใช้งาน (Getting Started)
```bash
npm install
npm run dev
```

## ความปลอดภัย
• การโหลด Source Code และการตั้งค่าระบบ สงวนสิทธิ์เฉพาะบนลิงก์แอดมินเท่านั้น
• ช่างทั่วไปเข้าใช้งานผ่าน User Link เฉพาะบุคคล
